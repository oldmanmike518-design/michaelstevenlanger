Prompt Duel

A voice game against AI opponents

The problem
Talking to AI usually means typing a request and reading a reply. Prompt Duel turns that into a contest: what you say is your move.
What it does
You speak or type your moves against AI opponents who answer in character, and an AI judge scores what you say. Its public description lists three modes: Arena, Interrogation, and Tribunal.
My part
I designed and built it. Its GitHub profile lists the stack: Groq, ElevenLabs, Firebase, Stripe, and Vercel.
What you can inspect
The game itself and its public GitHub profile. The source code is private.

Agent Sandbox

Interoperability checks for AI agents

The problem
AI agents are usually tested against the harness they were built with. That can miss what goes wrong with unfamiliar software: reading results out of order, handling a message twice, or treating text in the data as an instruction.
What it does
An agent runs a short verification against a partner agent the service operates. The service scores eight checks and publishes a dated report you can link to, with a badge.
Status: experimental public alpha. The specification is a draft and its thresholds are provisional.
My part
I built it: the API, scoring engine, specification, tests, and deployment setup. The commit history is public.
What you can inspect
The code, tests, and specification are public under the MIT license, and each report names the code commit that scored it. You can also verify an agent against the live service.
